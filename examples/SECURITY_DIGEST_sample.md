# 今週のセキュリティニュース（2026年10月9日）

こんにちは。町のお店や事務所、NPO のみなさんに向けて、最近公開された脆弱性、つまりソフトウェアや機器の「弱点」の情報をお届けします。

今回の注目は4件です。対象は、9月28日から10月9日までに JVN（ジェイブイエヌ）という、国内の脆弱性情報サイトで公開されたものです。ホームページの管理ソフト、Wi-Fi ルーター、複合機、そして毎日使うブラウザの話題を取り上げます。

なお、この原稿は公開時点の情報をもとにしています。最新の情報は、JVN や各メーカーのサイトで確認してください。

## 1. Movable Type でホームページを作っている方は要チェック

1つ目は、ホームページやブログを作るためのソフト「Movable Type（ムーバブル・タイプ）」です。自分で管理していなくても、制作会社に作ってもらったサイトで使われていることがあります。

今回見つかった弱点を悪用されると、サイトが動いているサーバーの上で、外部の人に勝手にプログラムを動かされたり、サイトのデータを読み書きされたりするおそれがあります。深刻度は、いちばん上の「緊急」です。サポートが終わった古いバージョンも影響を受けます。

対策は、修正版へのアップデートです。修正版は、9.3.0、9.0.10、8.8.6、8.0.13 などです。Movable Type Premium にも修正版が出ています。ご自身で更新できない場合は、サイトを作った制作会社や管理会社に「Movable Type の10月の修正版に更新済みか」を確認してください。すぐに更新できない場合の回避策もメーカーが案内しています。

## 2. バッファローの Wi-Fi ルーターと中継機をお使いの方へ

2つ目は、バッファロー製の Wi-Fi 機器です。対象は、ルーターの「WSR-300HP」と、電波を広げる中継機の「WEX-G300」の2機種です。

弱点を悪用されると、機器を外から勝手に操作されたり、機器が止まってインターネットにつながらなくなったりするおそれがあります。深刻度は「高」です。

対策は、ファームウェアと呼ばれる機器の中のソフトを、最新版に更新することです。WSR-300HP はバージョン2.55、WEX-G300 はバージョン1.71 で修正されています。自動更新をオンにしている場合は、すでに更新されている可能性があります。機器の裏や底にあるシールで型番を確かめてみてください。

## 3. 富士フイルムとシャープの複合機をお使いの方へ

3つ目は、コピー、プリント、スキャン、ファクスが1台でできる「複合機」です。富士フイルムビジネスイノベーション製と、シャープ製の複合機が対象です。対象の機種はかなり多いと案内されています。

複合機には、パソコンのブラウザから設定を変える「管理画面」があります。この管理画面にログインできる人が悪用すると、機器の中にある重要な情報を盗み出されるおそれがあります。深刻度は「中」です。

対策は、ファームウェアの更新と、メーカーが案内している回避策の実施です。複合機はリース契約で、保守を販売店が担当していることが多いと思います。「JVN で公開された複合機の脆弱性について、うちの機種は対象か」と販売店や保守の担当者に聞いてみてください。あわせて、管理画面のパスワードが初期設定のままになっていないかも確認しておくと安心です。

## 4. Chrome と Firefox は最新版に

4つ目は、インターネットを見るためのブラウザです。Google Chrome（グーグル・クローム）では、今回、数十件の弱点がまとめて公開されました。Mozilla Firefox（モジラ・ファイアフォックス）と、同じ会社のメールソフト Thunderbird（サンダーバード）にも、修正が出ています。

細工されたホームページを開いただけで、悪いプログラムを動かされるおそれがあるものも含まれています。深刻度は「緊急」のものがあります。

対策は、ブラウザを最新版に更新することです。Chrome は、画面右上の点が3つ並んだメニューから「ヘルプ」、「Google Chrome について」を開くと、更新の確認ができます。更新のあとは、ブラウザの再起動を忘れずに。Firefox と Thunderbird も、メニューから最新版に更新してください。

## まとめ：今週からできること

最後に、毎週使える3つの習慣です。

1つ目は、「迷ったらアップデート」です。ソフトや機器の更新のお知らせが出たら、後回しにせず更新しましょう。

2つ目は、「自動更新をオンに」です。ルーターやブラウザは、自動更新の設定があれば有効にしておくと、気づかないうちに守ってくれます。

3つ目は、「分からなければ聞く」です。ホームページなら制作会社、複合機なら販売店、ルーターならメーカーのサポートに、「この脆弱性の対策は済んでいますか」と聞くだけでも十分な一歩です。

この原稿は、JVN が公開した時点の情報をもとにしています。対象の機種やバージョンなどの詳細は、必ず JVN か各メーカーの最新の案内を確認してください。それでは、また来週。
